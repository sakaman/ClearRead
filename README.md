# ClearRead（净阅）

一个可扩展到多个网站的本地阅读增强 userscript。当前版本支持 `weibo.com` 网页端，可清理信息流广告、荐读和侧栏噪音，同时提供更舒适的排版、专注模式、视频自动播放控制与键盘阅读导航。

[![油猴一键安装 ClearRead](https://img.shields.io/badge/油猴-一键安装_ClearRead-ff8200?style=for-the-badge&logo=tampermonkey&logoColor=white)](https://raw.githubusercontent.com/sakaman/ClearRead/main/clearread.user.js)

主脚本：[clearread.user.js](./clearread.user.js)

项目采用站点无关的品牌名称，为后续增加知乎、X 等站点适配器预留空间；这些站点尚未包含在当前版本中。

## 功能

- 隐藏带明确广告属性的条目，以及位于微博卡片元信息区的“广告 / 推广”标记内容。
- 隐藏“荐读 / 推荐 / 热门推荐”等推荐信息流。
- 隐藏商业热搜项、侧栏推荐、创作者推广区和冗长页脚；普通热搜默认保留。
- 将发微博区域折叠为紧凑状态，聚焦或悬停时自动展开。
- 可调正文栏宽度和字号，并优化正文行距。
- 一键专注模式：隐藏右栏和发微博区域，让信息流居中。
- 阻止非用户触发的视频自动播放；用户主动点击播放仍然可用。
- 支持自定义屏蔽词和用户名称，规则只保存在本机。
- 支持 `J` / `K` 切换微博，`Alt + R` 切换专注模式。
- 兼容微博的 SPA 路由和虚拟滚动信息流；隐藏广告后会同步收起虚拟列表的缓存高度，新加载内容也会自动重新检查。

## 安装

点击上方“油猴一键安装 ClearRead”按钮，脚本管理器会自动打开安装确认页。若浏览器没有自动识别，请使用下面的手动安装方式。

一键安装版本已声明更新和下载地址。后续发布新版本并递增版本号后，Tampermonkey、Violentmonkey 等脚本管理器会按照各自的更新周期自动检查；也可以在扩展管理面板中手动检查更新。

1. 安装 Tampermonkey、Violentmonkey 或其他兼容 userscript 的浏览器扩展。
2. 打开扩展的“新建脚本”页面。
3. 删除模板内容，将 [clearread.user.js](./clearread.user.js) 的全部内容粘贴进去。
4. 保存脚本并刷新 `https://weibo.com/`。
5. 页面右下角出现“净阅”按钮即表示 ClearRead 已加载。

脚本不使用外部依赖，也不需要额外网络权限。

## 默认行为

下表中的“开启”表示相应净化或增强规则会生效。

| 设置 | 默认值 |
| --- | --- |
| 广告与商业推广 | 开启 |
| 荐读与推荐微博 | 开启 |
| 侧栏推荐内容 | 开启 |
| 微博热搜 | 关闭，保留普通热搜 |
| 侧栏页脚信息 | 开启 |
| 折叠发微博区域 | 开启 |
| 加宽正文栏 | 开启，默认 720px |
| 增强正文排版 | 开启，默认 16px |
| 专注模式 | 关闭 |
| 减少动画 | 开启 |
| 阻止视频自动播放 | 开启 |
| J / K 阅读导航 | 开启 |

所有选项都可以在右下角“净阅 ClearRead”面板中即时修改。扩展菜单还提供打开设置、切换专注模式、编辑屏蔽词、编辑屏蔽用户和手动重新检查页面等命令。

## 广告识别原则

脚本采用分层且偏保守的判断，避免因为正文刚好谈到“广告”就误删普通微博：

1. 优先识别 `feedtype="ad"`、`data-ad-id` 等明确广告属性。
2. 识别微博卡片元信息区域中独立出现的“广告 / 推广 / 荐读”等短标签。
3. 只在用户主动配置后应用正文关键词与作者规则。

命中的内容只会被添加隐藏样式，不会从微博服务器删除，也不会修改账号数据。关闭相应选项即可恢复显示。

## 隐私与边界

- 不读取 Cookie、密码、私信或浏览历史。
- 不上传设置，不调用第三方服务，不包含统计或遥测。
- 不拦截、伪造或修改微博 API 请求。
- “去广告”是页面呈现层清理，不等同于网络级广告拦截；资源可能已由页面下载。
- 微博网页结构发生变化时，个别规则可能暂时失效。脚本刻意避免依赖当前随机哈希类名，但仍保留少量已验证的稳定语义类名作为辅助信号。

## 开发与验证

检查 JavaScript 语法：

```powershell
node --check .\clearread.user.js
```

仓库还包含 [tests/fixture.html](./tests/fixture.html)，用于验证普通微博、广告、荐读、侧栏、动态新增内容，以及虚拟列表隐藏广告后的空白占位回归。通过任意本地静态服务器打开它即可；测试结果会显示在页面顶部。

例如：

```powershell
python -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/tests/fixture.html`。
